# Security Policy

## Scope

This repository is a public documentation and product showcase repository for FlowDesk.

It does **not** contain FlowDesk production application source code, production infrastructure, or customer data.

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability related to FlowDesk systems or services, please **do not** report it in a public GitHub issue.

Use GitHub's private vulnerability reporting capability for this repository when available, or contact the FlowDesk team through an established private channel.

If no private reporting channel is currently visible, open a minimal public issue requesting a secure contact path **without including vulnerability details**.

## What to Include in a Private Report

Please include:

- A concise description of the vulnerability
- Affected component or surface area
- Reproduction steps or proof-of-concept details
- Potential impact assessment
- Suggested remediation (if available)

## Public Disclosure Guidance

To protect users and systems:

- Do not post exploit details, credentials, tokens, customer data, or infrastructure identifiers publicly.
- Allow time for triage and remediation before any public disclosure.
- Share only sanitized information in public channels.

## Repository vs. Production Systems

This repository documents product direction and architecture at a high level. Security findings for private production systems may involve components that are not present here, but should still be reported privately.
