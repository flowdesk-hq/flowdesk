# Visual Assets Guide

This directory is reserved for authentic public visual assets representing the real FlowDesk product as it evolves.

Do not upload fabricated screenshots, mock telemetry, or customer-sensitive material.

## Planned Assets

| File | Purpose | Recommended Size | Notes |
| --- | --- | --- | --- |
| `logo.png` | Primary FlowDesk mark for repository branding | ~512×512 px (square, transparent background preferred) | Keep high contrast for dark surfaces |
| `banner.png` | Repository/social preview banner | ~1280×640 px | Should communicate product category and brand tone |
| `dashboard.png` | Command Center overview screenshot | ≥1600 px width | Capture real product UI with sanitized data |
| `inbox.png` | Unified Inbox interface screenshot | ≥1600 px width | Show realistic conversation workflows without PII |
| `booking.png` | Smart Booking interface screenshot | ≥1600 px width | Show availability/scheduling UI with anonymized content |
| `demo.gif` | Short product interaction walkthrough | 8–20 seconds, optimized for web | Use real interface interactions only |

## Visual Identity Direction

- Dark/black backgrounds
- Purple accent palette
- Minimalist SaaS aesthetic
- Clean typography
- Professional interface composition

## Quality and Safety Requirements

- Use authentic FlowDesk interface captures only.
- Remove or anonymize all sensitive/customer-specific data.
- Avoid exposing internal URLs, keys, IDs, or environment details.
- Keep file names stable to avoid broken references in documentation updates.
